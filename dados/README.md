# Dados

- `brutos/`: coletas gravadas pelo `ferramentas/capturar.py`. Cada coleta tem um `.csv` (linhas originais do firmware, com o tempo do PC na primeira coluna) e um `.json` (rótulo, participante, distância, parede, contagens).
- `graficos/`: imagens geradas pelo `ferramentas/plotar.py`.

Só entram aqui dados reais coletados pelo grupo. Nada de dados sintéticos ou de teste.
